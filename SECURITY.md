# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/dominiksmolinski3/KanbanProject/security/advisories/new),
not in a public issue or pull request.

Include what is affected, how to reproduce it, and what an attacker could do with it. You will get
an answer within a week, and a fix or a decision with its reasons as soon as the report is confirmed.

## Supported versions

Only the latest release and `main` receive fixes.
